# PortScanner-turkish-
Nmape özenerek yaptığım port tarayıcı NetScan aracı ilk olarak ağdaki aktif cihazları bulur sonra temel portları taramaktadır. 
Tabi ki nmap kadar güçlü değildir bunu yapmamdaki amaç herkesin nmap indirmeden basit şekilde analiz yapıp sonra o basit dosyayı silmesidir.
# Nasıl Kullanılır? 
Netscan.py dosyasını indirin ve istediğiniz bir klasörün içine atınız (örneğin masaüstü)
Netscan.py dosyasının bulunduğu klasörde kontrol paneli (terminal) açın
Açtığınız panele 
python Netscan.py 192.168.1.0/24
                      I
                      ∨
                  (Hedef IP)
yazınız ve hangi portların açık olduğunu görün.
